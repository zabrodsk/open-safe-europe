Open SAFE Europe / Design direction

An open agreement folder.

For European startup founders preparing their first investment agreement. The page has one job: help them start a SAFE draft.

Color and type

Ink #18233f
Cobalt #3554df
Desk #eef0f8
Paper #ffffff

Caption #5e6880

Bricolage Grotesque for restrained display headings. Noto Sans for forms and body copy. System monospace for source versions and document labels.

Layout exploration

B / Open folder
[ direct headline ][ SAFE folder tab ]
[ start draft    ][ actual term rows ]
[ source status  ][ document footer  ]
[ country choice and template status ]
[ drafting steps / ownership / sources ]

Chosen: B. A large typographic SAFE tab attached to a white agreement sheet makes the document itself the signature. No fake review stamps, stock startup imagery or floating badges.

Critique before building

A blue software dashboard would still be generic. The revised direction uses the proportions and layers of a physical agreement folder, with real investment labels inside. The rest stays quiet. Section numbers are removed except where they describe the actual three-step drafting process.

Preserve all app behavior. Test the forms, downloads, keyboard focus, reduced motion and narrow screens. Browser drafts remain local; agent API privacy stays explicit.
