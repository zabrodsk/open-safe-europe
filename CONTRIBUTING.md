# Contributing

Open an issue describing the user problem, or send a pull request with a focused change and relevant tests. Use fictional companies and investors in fixtures.

For templates, include the source, version, reuse permission, governing-law scope, intended entity types and whether qualified counsel has reviewed the exact text. A country name alone is not evidence of adaptation. Original generic templates must remain labelled as such.

Keep document generation deterministic. AI output must be displayed as a suggestion until a user chooses to incorporate it. Preserve export attribution and do not send an API key or private draft to analytics, logs or the project maintainers.

Run `npm test`, `npm run test:e2e` and `npm run build` before submitting changes. Do not claim legal correctness based on software tests.
